DisableHover native v2 test
===========================

1. Build Debug:
   dotnet build -c Debug

2. Start Cities: Skylines II.

3. Open Options > Modding.
   DisableHover must be present with:
   - Disable Tooltips
   - Disable Blue Highlights
   - Toggle Tooltips hotkey (default F8)
   - Toggle Blue Highlights hotkey (default F9)

4. In-game DH button:
   - normal/dark = at least one function is not disabled
   - blue = both functions are disabled
   - reddish/dim = the C# backend did not register

5. Click DH once. In Player.log you should see:
   Toolbar DH clicked. Both DisableHover functions = True/False

6. Test one-click building selection and creating/connecting train lines.
